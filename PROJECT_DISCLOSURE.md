# Project disclosure

VÉRTICE / Agents for Humans is being created during the hackathon submission period.

## Human contribution

The human entrant defines the product objective, problem framing, authority model, risk tolerance, demo scenario, public identity, submission decisions, and final acceptance. Account creation, identity-bearing actions, public publication, deployments with external consequences, and final submission remain human-controlled.

## AI-assisted contribution

AI assistance has been used for implementation, test design, documentation, release-gate construction, adversarial review, and drafting submission material. AI-generated output is reviewed through executable tests and release checks; it is not treated as evidence merely because it was generated.

## Third-party/open-source components

The project uses standard open-source development dependencies including the Strands Agents SDK, FastAPI, Uvicorn, and HTTPX. Their presence does not imply authorship by the entrant.

## Demonstration data and truth labels

The included proposal, buyer, amount, work steps, and external business effect are synthetic demonstration data. No real customer data is included. The consequential external effect is intentionally **SIMULATED** in the hackathon prototype. `REAL_STRANDS` may only be claimed by evidence produced from an actual run with the pinned official SDK; `REPLAY` denotes a repeated execution attempt that must not create a second effect.
