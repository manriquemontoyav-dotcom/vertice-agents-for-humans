# Official Requirements Map

Verified against the hackathon rules on 10 September 2026 UTC.

| Submission expectation | Automated evidence | Remaining human evidence |
|---|---|---|
| Built with Strands Agents | dependency, import, README explanation | working demo review |
| Public source repository | sanitized source-tree checks | publication and accessible URL |
| MIT or Apache-2.0 | root license text | final repository inspection |
| README and architecture | required sections and diagram | clarity/editorial review |
| Reproducible testing | commands, dependencies, CI workflow | remote CI result |
| Pre-existing work disclosure | contribution disclosure check | factual confirmation |
| Demo consistent with project | truth labels and no placeholders | browser/video parity gate |
| Public video up to five minutes | not evaluated by this kit | final video URL and duration |
| AWS Builder ID | not evaluated by this kit | Manuel confirmation |

The gate intentionally does not infer completion of account, publication,
video, live runtime, or submission requirements from repository contents.
